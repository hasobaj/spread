# Project 02 - Interface Writing 
**by Leila & Hannah**

Project 02 was a class assignment where each group had to choose a different article and turn it into a website. This website is based on the reading [*Interface Writing: Code for Humans*](https://www.nicolefenton.com/interface-writing/) by Nicole Fenton.  

The article talks about how the words used in digital spaces affect the way people understand and interact with them.

Another part of the assignment was learning how to work cooperatively with a partner. Both partners were only allowed to work on the website at the same time, which required planning, organizing and making design decisions together.

## Approach 
One of the main rules was that no images could be used. This was a challenge because the original article uses a lot of pictures to explain its ideas.

Instead of leaving those parts out, the goal was to find ways to recreate the feeling of the images using only typography. We used different type, sizes, placements and spacing to make certain parts of the text more visual. So we designed it to stay connected to the original article without needing the actual images.
